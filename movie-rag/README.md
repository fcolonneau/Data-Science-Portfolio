Movie RAG Assistant
A Retrieval-Augmented Generation (RAG) system for movie recommendations using semantic search and evaluation metrics.
Overview
Movie RAG Assistant is a Python-based application that recommends movies based on user queries using semantic search. It leverages a pre-trained SentenceTransformer model (all-MiniLM-L6-v2) to encode movie genres and descriptions, enabling relevant movie retrieval. The system evaluates performance with Precision@K and Recall@K metrics using a predefined set of test queries.
Key features:

Semantic Search: Retrieves movies by computing cosine similarity between query and movie embeddings (genre + description).
Evaluation: Measures retrieval performance with Precision@K and Recall@K.
Streamlit Interface: User-friendly interface for querying and evaluating results.
No External Dependencies: No MongoDB or Docker required, runs locally.

Prerequisites

Python 3.10 (recommended to avoid compatibility issues)
pip for installing dependencies
Git for cloning the repository

Installation

Clone the repository:
git clone https://github.com/fcolonneau/movie-rag.git
cd movie-rag


Create and activate a virtual environment:
python3.10 -m venv venv
source venv/bin/activate  # On Windows: .\venv\Scripts\activate


Install dependencies:
pip install -r requirements.txt

The requirements.txt includes:
pandas==2.2.2
numpy==1.26.4
nltk==3.8.1
sentence-transformers==2.6.1
scikit-learn==1.5.0
streamlit==1.36.0
torch==2.2.2


Ensure the dataset top_movies.csv is in the project root. It should contain columns: movie_name, genre, description.


Usage

Run the Streamlit application:
streamlit run app.py


Open your browser at http://localhost:8501.

Querying:

Enter a query (e.g., "mafia movies") in the input field.
Adjust the number of results (default: 5) using the slider.
Click "Search" to view results, including a hook and detailed movie information.


Evaluation:

Click "Run Evaluation" to compute Precision@K and Recall@K for predefined test queries.
Results are displayed in a table with average metrics.



Project Structure

app.py: Main Streamlit application for user interaction and evaluation.
preprocessing.py: Loads and preprocesses top_movies.csv, generates embeddings for genre + description.
rag.py: Performs semantic search using cosine similarity and generates a response hook.
evaluate.py: Computes Precision@K and Recall@K for test queries.
top_movies.csv: Dataset with movie names, genres, and descriptions.
requirements.txt: List of Python dependencies.
data/embeddings.npy: Cached embeddings for movie data.

Dataset
The top_movies.csv file contains a collection of movies with:

movie_name: Title of the movie (e.g., "The Godfather").
genre: Genre(s) of the movie (e.g., "Crime Drama").
description: Brief plot summary.

Embeddings are generated by combining genre and preprocessed description using SentenceTransformer.
Evaluation
The evaluation measures the performance of the semantic search using Precision@K and Recall@K:

Precision@K: Proportion of the top K retrieved movies that are relevant.
Recall@K: Proportion of relevant movies retrieved among all relevant movies.
